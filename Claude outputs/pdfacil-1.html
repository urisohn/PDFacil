PDFacil

An easy PDF viewer (fácil: 'easy', in Spanish)

Version 1.1.1 · November 2026 · Created by Uri Simonsohn with Claude Opus 5.5

PDFacil is a PDF viewer for Windows and Mac, designed for researchers who read papers in PDF format. The Home menu on top has all the tools one needs:

The Home menu

Installation on Windows

Download PDFacil Version 1.1.1 · zip file, about 150 MB · Windows 10 and 11 (64-bit)
  1. Download the zip file above.
  2. Unzip it.
  3. No install needed: just run PDFacil.exe inside the unzipped folder. Keep all the files in that folder together.

The first time you run it, Windows may say "Windows protected your PC", because the app is not code-signed. Click More info, then Run anyway.

Installation on a Mac

There is no ready-made Mac download yet, but you can build PDFacil on your Mac in a few minutes, without any programming:

  1. Install Node.js (version 20 or newer).
  2. Open Terminal and run these lines one by one. The first time you use git, macOS offers to install it; click Install. 
    git clone https://github.com/urisohn/PDFacil.git
cd PDFacil
npm install
npm run dist
  3. Open the new PDFacil/dist/mac-arm64 folder (dist/mac on older Intel Macs) and drag PDFacil.app into your Applications folder.

More details, including what to do if macOS refuses to open the app, are in the instructions on GitHub.

Make PDFacil your default PDF viewer

Windows: right-click any PDF file, choose Open with > Choose another app, browse to PDFacil.exe, select it, and tick Always.

Mac: select any PDF in Finder, choose File > Get Info, pick PDFacil under Open with, and click Change All.
